# NCKU DAQ 專案

這是一個用於接收與記錄設備數據的專案，主要包含三個 Python 程式，負責處理不同設備發送的 TCP 及 Modbus 訊號。

## 檔案說明

### 1. `tcp_receiver_v1.py` (基礎版 TCP 接收程式)
- **前身**：`tcp_receiver.py`
- **功能**：這是一個基本的 TCP Server，主要用來接收來自 ICPDAS WP-8121 PAC 控制器的二進位資料（Burst data）。
- **特點**：收到資料後會直接儲存為當前目錄下的 `burst.bin` 檔案。由於沒有區分設備 IP 跟加上時間戳記，每次收到新資料都會覆蓋舊檔案。
- **適用場景**：適合做簡單的單機通訊測試或資料傳輸驗證。

### 2. `tcp_receiver_v2.py` (進階版 TCP 接收程式)
- **前身**：`tcp_saver.py`
- **功能**：基於 `v1` 改良的進階版 TCP Server，同樣用於穩定接收 ICPDAS 系列控制器的二進位資料。
- **特點**：
  - **自動分類**：會根據來源設備的 IP 位址自動把資料分存到不同資料夾（例如 `192.168.1.12` 自動歸類為 `machine1`，`192.168.1.13` 歸類為 `machine2`）。
  - **保留紀錄**：自動在輸出的 `.bin` 檔案名稱後方加上「日期_時間」的時間戳記（例如 `machine2_20260321_165647.bin`），不會覆蓋到舊有資料，方便後續歷史存查。
  - **集中管理**：資料統一儲存至 `C:\Users\USER\Desktop\data` 中。
- **適用場景**：適合實際上線且有多台設備同時持續傳輸資料的情境。

### 3. `temp_receiver.py` (溫度資料記錄程式)
- **前身**：`pt100_logger.py`
- **功能**：透過 Modbus TCP 協定（Port 502）直接讀取 ET-2215H / ET-2215H-16 等 PT100 遠端溫度模組的資料。
- **特點**：
  - 預設每 10 分鐘（600 秒）定期採樣一次。
  - 自動讀取所有通道（支援 8/16 通道）的數值，換算成正確「攝氏溫度」，並會自動判斷該通道是否斷線。
  - 資料存成附有啟動時間戳記的檔案（如 `pt100_data_20260327_111830.bin`），統整儲存在 `C:\Users\USER\Desktop\data\temp` 目錄，格式內含 64-bit Timestamp 與各個通道的 32-bit Float 數值，這對後續大數據和圖表分析非常有幫助。

## 執行方式
在使用前，請確保已安裝所需的第三方套件庫（例如 `pymodbus` 等）：
```bash
pip install pymodbus
```


然後在命令提示字元 (CMD) 或 PowerShell 中，切換到該程式所在目錄執行對應程式即可：

**👉 一鍵啟動 (推薦)**
可以直接執行 `main.py`，它會自動幫您跳出兩個新的終端機視窗，分別執行 `v2` 與 `temp` 接收程式：
```bash
python main.py
```

**👉 單獨啟動**
如果只需要啟動單一收資料的程式：
```bash
python tcp_receiver_v2.py
```
*(請依照您的需求換成當下想要啟動的單一程式檔名)*
